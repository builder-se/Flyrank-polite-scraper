# The Polite Scraper

## Target classification

- Target: Books to Scrape
- Why it is appropriate: Books to Scrape is a sandbox specifically intended for practicing web scraping.
- Scope: Only the first 3 catalogue pages will be processed.
- Data to be collected eventually: book title, price, rating, availability, category, description, and cover image URL.
- robots.txt result: Checking https://books.toscrape.com/robots.txt returned no robots file found. This does not imply permission to scrape.

I will not reuse this code on another site without checking its rules and terms first.
